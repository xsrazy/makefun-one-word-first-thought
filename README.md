One word, first thought: a tiny program that writes a single surprising word to `/output/entry.txt` for make.fun's "One Word, First Thought" bounty. No topic, no explanation, no second draft — just the word, nothing else.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
